# Afficher les prix avec toutes les décimales (3 au lieu de 2)

## Contexte

La base stocke les prix en `Numeric(5,3)` (3 décimales). L'API renvoie le float exact sans arrondi.
Le frontend arrondit systématiquement à 2 décimales via `toFixed(2)` dans 3 fonctions.

## Changements

### 1. `web/src/utils.ts` — `formatPrice()` (ligne 48-50)

```ts
// Avant
return `${price.toFixed(2).replace(".", ",")} €`;
// Après
return `${price.toFixed(3).replace(".", ",")} €`;
```

### 2. `web/src/utils.ts` — `formatDelta()` (ligne 53-55)

```ts
// Avant
return `+${delta.toFixed(2).replace(".", ",")} €`;
// Après
return `+${delta.toFixed(3).replace(".", ",")} €`;
```

### 3. `web/src/components/MapView.tsx` — `formatPriceLabel()` (ligne 47-49)

```ts
// Avant
return price.toFixed(2).replace(".", ",");
// Après
return price.toFixed(3).replace(".", ",");
```

## Fichiers concernés

- `web/src/utils.ts` (2 modifications)
- `web/src/components/MapView.tsx` (1 modification)

cd web && npx tsc --noEmit   # pas d'erreur de types
